# Waveform Images

This folder is reserved for generated waveform screenshots captured from GTKWave after a simulation run.

Suggested workflow:

1. Run a Verilog testbench to generate a VCD file.
2. Open the VCD in GTKWave.
3. Save a waveform screenshot or export a PNG for the documentation page.

The repository intentionally does not include fake screenshots. Use real waveform captures from your local simulator runs.
